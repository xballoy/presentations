# AI Fundamentals for Beginners

> A 60-minute introduction to AI for a general audience in Valais/Wallis: one plain-language analogy, three live demos grounded in everyday Swiss admin/health/translation tasks, and a dedicated section on scams and misconceptions.

View the presentation online:

- [English version](https://xballoy.github.io/presentations/ai-for-beginners/en/)
- [French version](https://xballoy.github.io/presentations/ai-for-beginners/fr/)

## Development

From the repository root:

- `pnpm install`
- `pnpm dev:ai-for-beginners`
- visit [http://localhost:3030](http://localhost:3030)

`pnpm dev:ai-for-beginners` opens the English deck. To open a specific language directly:

- `pnpm --filter ai-for-beginners dev:en`
- `pnpm --filter ai-for-beginners dev:fr`
